# 💰 Expense Tracker

A modern full-stack *Expense Tracker SaaS application* built with production-ready practices.

This project demonstrates real-world concepts such as authentication, protected APIs, user-specific data isolation, preferences, analytics, and cloud deployment — with a clean and responsive UI.

---

## 🌐 Live Demo

- *Frontend (Vercel)*  
  https://expense-tracker-nine-pearl-63.vercel.app

- *Backend API (Render)*  
  https://expense-tracker-5m1n.onrender.com

---

## ✨ Features

- User authentication (JWT-based)
- Secure password hashing
- Multi-user data isolation
- Add, edit, and delete expenses
- Card & table views
- Analytics dashboard
- Light / Dark mode
- Currency, language & date preferences
- Fully responsive design
- Deployed frontend & backend

---

## 🛠 Tech Stack

*Frontend*
- React (Vite)
- React Router
- Context API
- Tailwind CSS
- Axios

*Backend*
- Node.js
- Express
- MongoDB Atlas
- Mongoose
- JWT Authentication

*Deployment*
- Frontend: Vercel  
- Backend: Render
